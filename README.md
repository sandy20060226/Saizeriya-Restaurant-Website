# 薩莉亞餐廳介紹網站 | Saizeriya Restaurant Website

## 專案簡介

本專案為大學 HTML 網頁設計課程的實作作品，以薩莉亞（Saizeriya）餐廳為主題，運用 HTML、CSS 及基礎 JavaScript 製作多頁式介紹網站，提供餐廳資訊、菜單展示、分店介紹及意見回饋介面。

透過本次專案，學習網站架構規劃、網頁排版、頁面導覽與基本互動功能的實作。

## 使用技術

- **HTML**：建立網頁架構與內容
- **CSS**：設計網頁版面、字體及視覺樣式
- **JavaScript**：實作菜單圖片輪播功能

## 主要功能

1. **首頁導覽**：提供各介紹頁面的入口及相關連結。
2. **餐廳介紹**：呈現薩莉亞的品牌理念與餐廳特色。
3. **菜單展示**：透過圖片輪播方式瀏覽餐點資訊。
4. **分店介紹**：以圖片與文字介紹分店位置及特色。
5. **意見回饋**：設計姓名、用餐店鋪、Email 及意見輸入表單。
6. **推薦網站與架構說明**：介紹其他推薦網站及本專案的設計理念。

## 專案特色

- 採用多頁式網站架構，透過導覽列切換不同頁面。
- 以綠色與白色為主要配色，呼應薩莉亞的品牌形象。
- 使用 CSS 進行網頁排版與視覺設計。
- 運用 JavaScript 製作圖片輪播，增加網站互動性。
- 設計意見回饋表單介面，練習 HTML 表單元素的應用。

## 學習收穫

透過本次專案，我學習到如何從網站架構規劃開始，逐步完成網頁內容、版面設計與功能實作，並了解不同頁面之間的連結與整合方式。這次經驗也讓我對網站開發產生更濃厚的興趣，為後續學習 ASP.NET Core MVC 及資料庫應用奠定基礎。
